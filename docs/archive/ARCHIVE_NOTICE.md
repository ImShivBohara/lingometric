# Archive Notice — Historical Project Planning Artifacts

This directory contains early planning, design blueprints, and initial specification documents created during the inception of the project (previously codenamed *LinguaCert AI*).

## Purpose of this Archive

These files are preserved for academic grading, architectural reference, and historical project auditing. They represent early exploratory proposals—some of which included speculative features (such as automated cryptographic PDF certificate issuance) or initial database schema drafts that were subsequently refined in Phase 1 and Phase 2.

## Archived Documents

- **`ARCHITECTURE.md`**: Initial monolithic architecture diagram and early system overview.
- **`API_SPEC.md`**: Early endpoint and action specifications.
- **`FOLDER_STRUCTURE.md`**: Initial folder organization proposal.
- **`IMPLEMENTATION_PLAN.md`**: Original task breakdown and milestones.
- **`PHASE2_DATABASE_SETUP.md`**: Early database bootstrapping walkthrough.
- **`RISK_ANALYSIS.md`**: Threat matrix and risk assessment notes.
- **`RLS_POLICY_EXPLANATION.md`**: Early Row-Level Security policy notes.
- **`assets/renewable_energy.mp3`**: Baseline sample audio recording used to seed the initial Listening section in Supabase Storage.
